Claude · MCP Tasks & Skills
NewAgentsPipeline

Claude's MCP support grows up: long-running tasks and Skills

Anthropic made MCP Tasks and Elicitation generally available in Claude on 24 Nov, and put Skills over MCP into public beta. Tasks let a connected server run a job that takes a while and report back; Elicitation lets a server stop and ask the user for missing input; Skills let a server ship its own instructions for how it should be used.

This lands as creative apps open up to agents: Adobe launched an MCP server alongside its MAX AI updates, and Maxon added one to Cinema 4D 2026.4 in September.

WHY IT MATTERSRenders, exports and batch conforms are long jobs. Support for long-running tasks and mid-job questions is what moves "an assistant that drives After Effects or C4D" from a demo towards something you could leave running on a real batch.

⚠️ Heads-up: Photoshop and AI labels

DPReview reports that The New York Times asked freelance photographers to keep using older Photoshop versions, because newer builds with generative features may mark files as AI-edited. Newsrooms, agencies and broadcasters with strict provenance rules should check what their current Creative Cloud builds write into metadata.

Big picture · models & research

Inkling 2 Mini

Inkling 2 Mini, open and local

Thinking Machines Lab released Inkling 2 Mini on Hugging Face (20 Nov): an open multimodal model with about 26B parameters, of which only 3B are active at a time, so it can run on a workstation. Useful for offline tagging and shot logging.

GLM-5.4

GLM-5.4's looped transformer

Z.ai launched GLM-5.4 on 23 Nov, which it calls the first looped-transformer model: the same layers are run several times instead of stacking more of them. Open weights are planned; for now access is through its paid coding plan.

AI does maths

AI proofs go big

A researcher working with Claude published a claimed formal proof of the Riemann hypothesis in Lean, around 17 million lines long (20 Nov). Mathematicians expect months of review. OpenAI and Google also posted unreviewed AI-assisted maths results this week.
